# Markdown Previewer

A small live Markdown editor/previewer. Plain HTML/CSS/JS, no build step,
no dependencies — `markdown.js` is a from-scratch parser covering a
practical subset of Markdown (headers, bold/italic, inline code, links,
fenced code blocks, blockquotes, ordered/unordered lists). It's not a
full CommonMark implementation, just enough for everyday notes.

## Usage

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server
```

Type Markdown in the left pane, see it rendered in the right pane as you go.
